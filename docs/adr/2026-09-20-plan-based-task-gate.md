# ADR-066: 改善タスクのゲートをプラン基準にし、基礎スコアの MEO 枠を再配分する

## 日付
2026-09-20

## 状況

改善タスクの Teaser ロックが**構造的に解除されない**状態だった（#84）。原因は2つ重なっていた。

### 問題1: ロックの向きが逆立ちしていた

閾値は優先度から機械的に決まっていた。

```java
case B -> new RemediationPriorityLevel(1, 0.0);   // 常に見える
case A -> new RemediationPriorityLevel(2, 60.0);  // 60点で解放
case S -> new RemediationPriorityLevel(3, 80.0);  // 80点で解放
```

つまり**優先度が高い（＝真っ先にやるべき）タスクほど、高いスコアを要求される**。

```
S級タスクを読みたい  →  80点必要
80点にしたい        →  S級タスクを実行する必要がある
                        ↑ しかし読めない
```

**助言を最も必要とする相手にだけ助言が届かない**構造だった。

### 問題2: 業種によっては閾値に到達できなかった

基礎スコアは AI ルーブリック50 ＋ MEO 25 ＋ 機械可読性25。MEO は Google マップのクチコミ由来で、**法人向け SaaS・オンラインサービスには Google マップの実体が無い**。

```
AI ルーブリック 50 ＋ 機械可読性 25 ＝ 最大 75点  <  閾値 80点
```

権威軸（`GeoVisibilityCalculatorService.authorityLocalMeoSub`）は同じ問題に対して「非地域業種は MEO 枠をゼロにして再配分する」手当を既に持っていたが、基礎スコア側には無かった。

## 決定（オーナー確定 2026-09-20）

### 1. ゲートはプラン基準にする

| 優先度 | Standard | Pro / Expert |
|---|---|---|
| B級・A級 | 全文表示 | 全文表示 |
| S級 | **ロック**（「Proプランで解放されます」） | 全文表示 |

スコアと無関係に解除条件が決まるため循環しない。核③（Teaser による Pro へのアップセル誘導）とも整合する。

`RemediationPriorityLevel.requiredScoreThreshold` は**撤去**した。スコア基準の判定を残すと、いずれ「どちらが本物か」が分からなくなる（`.cursorrules` 10節・Shadow Implementation 禁止）。

#### 伏せるのは手順だけ

ロック時も `title` と `rationale`（なぜ効くか）は見せ、`content`（実装手順）と `evidence`（裏付けの引用）だけを伏せる。全部隠すと価値が伝わらず、アップセルとしても機能しないため。

### 2. 非地域業種は MEO 枠を落として再配分する

| 業種 | AI ルーブリック | MEO | 機械可読性 |
|---|---|---|---|
| 地域業種（`LOCAL_STORE`） | 50 | 25 | 25 |
| 非地域業種（`CORPORATE_SERVICE` / `ONLINE_SERVICE`） | 66.7 | **枠ごと無し** | 33.3 |

満点は業種を問わず100点に保つ。**満点が業種で変わる方式は採らない** — 他社比較・経時比較の読みが壊れるため。

「MEO が 0 点」と「MEO の枠が無い」は意味が違う。前者は評価対象なのに取れていない状態、後者は評価対象ですらない状態で、後者を 0 点として平均に混ぜると業種の違いが減点に化ける。

## 補足: 「基礎スコアが全ジョブ NULL」は是正済み

`JobBenchmarkCaptureService.capture` に `@Transactional` が無く、RLS の GUC 未設定で projects を読めずに静かに早期 return していたのが原因だった。既に是正され、成否のログも入っている。本 ADR の範囲外。

## 影響

- マイグレーション不要
- API: `required_score_threshold` が消え、`requires_pro_plan`（真偽）が増える。`is_masked` の意味は「プランで伏せられている」に変わる
- `TaskRegenerationService` の文体再生成も同じ規則でロックする（伏せた本文は再生成もできない）
- 非地域業種の基礎スコアが上がる。従来は同じサイトでも業種指定だけで最大75点に抑えられていた
