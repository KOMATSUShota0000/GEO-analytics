# ADR-099: 公開デモに、4人のAIの議論の表示を入れる

## 日付

2026-09-30

## 状況

公開デモ（`/demo`、GitHub Pages）は、本番と同じ部品に見本のデータを流して見せている（#188、ADR-090）。「4人の議論」は、本番の表示ができてから入れることにしていた。LIVE-5・6（#199・#200、ADR-097・098）で、本番の結果画面に議論中の表示と、議論のあとの1行が入った（#234）。

- デモの流れは、入力 → 待ち表示（3.2秒）→ 結果。議論の表示は無い
- デモの見本データ（架空の工務店）は、見本の議論（改善タスク5件・ロードマップ 1／2〜3／4〜5・少数意見）とすでにそろっている
- 本番の議論の表示は、実際の画面でまだ確かめられていない（画面のテストを動かす仕組みが無く、解析を流すには費用がかかる）。デモに入れれば、解析を流さずにブラウザで確かめられる

## 決定

### 1. デモの流れに「議論中」を足す

入力 → 待ち表示 → **議論中** → 「結果を見る」→ 結果、にする。

- 議論中は、本番と同じ `DebateLivePanel` に見本の発言を渡す。デモ専用の見た目は作らない
- 発言は3秒ごとに1件ずつ届ける。本番は1発言に十数秒かかるが、デモでは1発言を流し終える長さに合わせ、7件を20秒ほどで見せる
- 急ぐ人のために、「議論を飛ばして、結果を見る」を置く
- 結果では、総合診断の上に、本番と同じ `DebateSummaryRow`（「議論の流れを見る」）を出す

### 2. 見本の発言は、本番と同じ形にする

`publicDemoSample.ts` に7件（2ラウンド×3人＋まとめ役）を足した。見本の画面（#199 に書き写したもの）の発言をもとにしている。

- 要約は本番の上限（120文字）に収めた
- 議論の結論が、デモの改善ロードマップと少数意見にそのままつながるようにした
- **根拠は本番で出せる種類だけを使う**。見本の画面には「AIが引用したページ」を根拠にした発言があったが、本番ではまだ測っていない（EVID #208）。「回答によく出た他社」に置き換え、文も「AIが紹介していたのは A社か B社でした」に直した
- 他社名は、デモのほかの見本と同じく「A社」「B社」にした

## 確かめたこと・確かめていないこと

- `npm run build` と、GitHub Pages 用の `npm run build:pages` が通る
- 見本の発言を本番の部品で Node 上に描画し、返事の札・根拠の枠・件数（2ラウンド・発言7件・根拠4か所）を確かめた
- **ブラウザでの見た目と動きは、公開後にオーナーが確かめる**。本番の部品（LIVE-5・6）の見た目の確認も、これで兼ねる

## 結果

| 変更 | `demo/publicDemoSample.ts`（見本の発言7件）、`pages/PublicDemoPage.tsx`（議論中の段階、結果に議論のあとの1行） |

- 本番に「AIが引用したページ」の根拠が入ったら（EVID #208）、見本の発言にも足せる
