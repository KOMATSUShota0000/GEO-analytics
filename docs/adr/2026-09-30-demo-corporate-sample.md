# ADR-100: 公開デモの見本を、企業向け（勤怠管理のクラウド）の想定に書き直す

## 日付

2026-09-30

## 状況

公開デモ（`/demo`）に4人のAIの議論の表示を入れ（#234、ADR-099）、オーナーがブラウザで確かめた。そこで2点の指摘があった（#236）。

- 議論の最初の発言に「地名が入った質問」「地名なしの質問」とあり、何のことか伝わらない。デモに載せる文章として、地名の話は要らない
- 解析の依頼では、事業の種類を3つ（地域密着・店舗型／企業向け・専門サービス／ネット通販・Webサービス）から選ぶ。デモの文章は「企業向け・専門サービス」を選んだ想定にしたい。見る人が想像しやすいため

デモの見本は、議論だけでなく全体（質問の例・サイト診断の10項目・スコアの内訳・改善タスク・ロードマップ・少数意見）が、「地域密着・店舗型」の架空の工務店で作られていた（ADR-090）。「地名」の話はそこから来ている。

あわせて、議論の発言をコピーすると同じ文が2回入ることがわかった。読み上げソフト用の全文を、見えない形で常に持たせていたため。

## 決定

### 1. 見本の会社を、中小企業向けの勤怠管理のクラウドに入れ替える（2026-09-30 オーナー確定）

議論だけを直すと、ほかの部分と食い違う。デモ全体を1つの会社の状況から組み立て直した。

| 部分 | 中身 |
|---|---|
| 状況 | AIに聞いた10の質問のうち、サービス名が出たのは、シフト勤務に触れた2問だけ。比較や料金を聞いた8問では、競合2社（A社・B社）が紹介されている |
| 原因（サイト診断） | トップページの冒頭がキャッチコピーだけで、何のサービスかが書かれていない。よくある質問のページが無い。料金が「お問い合わせください」だけ |
| 改善タスク（5件） | 1 冒頭で何のサービスかを伝える／2 導入事例に「導入前に何に困っていたか」を書き足す／3 よくある質問のページを作る／4 料金ページに1人あたりの月額の目安を書く／5 IT製品の比較サイトに掲載を依頼する |
| ロードマップ | 今すぐ 1／1〜3ヶ月 2〜3／3〜6ヶ月 4〜5 |
| 少数意見 | 導入事例12件すべてに書き足してから公開する案 |
| 議論 | 上の結論に至る2ラウンドと、まとめ役の一言 |

- 「社名」は「サービス名」と書いた。クラウドのサービスでは、AIの回答に出るのはサービスの名前のため
- 他社名は、今までどおり「A社」「B社」にした
- 効果・かかる時間の並び（効果 大×2、効果 中×2、効果 小×1）と、診断10項目の判定の内訳は変えていない。内容の点（25.0）と改善タスクの鍵のかかり方は、今までと同じ

### 2. スコアの内訳を、企業向けの本番の計算に合わせる

企業向けは Google マップに実体を持たないので、本番の計算（`GeoVisibilityCalculatorService`）では「地域の評判」の枠が無く、第三者からの言及が 0〜30 点になる（素点 0〜20 を1.5倍にする）。

| | 工務店（今まで） | 勤怠管理のクラウド（今回） |
|---|---|---|
| 内容 | 25.0 | 25.0 |
| 構造 | 12.0 | 12.0 |
| 権威 | 9.5（第三者言及 7.5 ＋ 地域の評判 2.0） | 10.5（第三者言及のみ。素点 7.0 × 1.5） |
| 合計 | 46.5 | 47.5 |

スコアの内訳の部品（`GeoScoreBreakdown`）に事業の種類を渡し、本番と同じく「地域の評判」の欄を出さないようにした。

### 3. 見えない全文を持たせるのは、文字を流している最中だけにする

流し終えた発言は、文を1回だけ持つ。コピーしても2回入らない。流している最中は、読み上げソフトに途中の文ではなく全文を渡すため、今までどおり見えない全文を持たせる。

## 確かめたこと・確かめていないこと

- 書き直した見本を本番の部品で Node 上に描画し、議論・スコアの内訳（47.5 点、「地域の評判」の欄が無い）・ロードマップ・少数意見の文言を確かめた。古い想定の言葉（工務店・地名・施工 など）が残っていないことも確かめた
- 流し終えた発言に、見えない全文が残らないことを確かめた
- `npm run build` と `npm run build:pages` が通る
- **書き直した文章は、公開後にオーナーが確かめる**

## 結果

| 区分 | ファイル |
|---|---|
| 変更 | `demo/publicDemoSample.ts`（見本の入れ替え、事業の種類）、`pages/PublicDemoPage.tsx`（事業の種類を渡す）、`components/debate/DebateTranscript.tsx`（見えない全文は流している最中だけ） |

既存のコメントのうち、見本の入れ替えで事実と合わなくなる2つ（ファイル冒頭の「架空の工務店」、スコアの内訳の式）は、オーナーの許可を得て書き換えた。

- README の画像（#190）を撮るときは、この見本か、本番の画面を使う
