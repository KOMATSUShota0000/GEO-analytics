# 何がどの順で効くか（全体の整理）

各段階の根拠は、それぞれのファイルにある。ここには全体の形だけを書く。

## 2つの系統

AI に引用・推薦される道は2つある。自社サイトを経由する道（直列）と、外部を経由する道（並列）。

### 自社サイト経由（直列。前の段階で止まると、後ろは効かない）

1. **届く**：AI のクローラーが取りに来られる。robots.txt やボット対策で検索用・都度取得のクローラーを止めていない → `crawlers-and-access.md`
2. **読み解ける**：JavaScript を実行しなくても、HTML に本文がある。タブや画像や PDF に閉じ込めていない → `crawlers-and-access.md`
3. **候補に入る**：検索索引に入り、質問（とその展開先の質問）で検索の候補に上がる → `trust-signals.md`、`citation-selection.md`
4. **引用したくなる**：候補の中で、統計・出典・冒頭の答え・見出しや表などで引用の取り分を増やす → `citation-selection.md`

- 1 は公式に前提とされている。OpenAI・Perplexity は、検索用のクローラーを拒否したサイトを回答に出さないと書いている。Google は、索引に入っていてスニペットを出せることを AI による概要の条件にしている
- 4 の効果は、3 を通った後にしか働かない。本文の工夫は、候補に入るかどうかを変えない（`citation-selection.md` の CITECHOICE と批判的レビュー）

### 外部経由（並列。自社サイトを通らずに効く）

5. **外での裏付け**：第三者のサイトでの言及（報道・Wikipedia・Q&A サイト・業界メディア）、地図情報と口コミ、学習で覚えられた知識 → `trust-signals.md`、`japan-market.md`

- 自社サイトが読めなくても、AI は第三者のページ、掲載情報、学習済みの知識から会社を推薦できる
- 調べた中で、いちばん一貫して引用・推薦と相関するのはこの系統（相関で、因果は未確認）

## 仮説の判定（2026-10-10）

- H1「GEO は 届く → 読み解ける → 引用したくなる → 外でも裏付けがある の4段階で整理でき、前で止まると後ろは効かない」：一部支持
  - 支持する点：届く・読み解けるが後ろの前提であることは、公式の記述と JavaScript の測定から言える
  - 支持しない点：「外での裏付け」は前の段階を通らずに効くので、直列の最後には置けない。また「読み解ける」と「引用したくなる」の間に「候補に入る」が抜けていた
  - 直した形が、上の2系統（直列4段階＋並列1つ）
